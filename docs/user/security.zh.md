# 安全策略

[English](security.md) | 中文

此个人实验性衍生项目在 `aipm` 分支接收安全修复，目前没有受支持的生产安装包版本。

## 报告漏洞

如果本仓库提供 **Security → Report a vulnerability**，请使用该私密渠道。否则可先提交 Issue 请求私密联系方式，不要附上利用细节、token、个人数据或保密文件。除非也能在上游软件复现，否则请勿把此衍生项目的漏洞报告发给上游维护者。

## 分享报告前

移除 API Key、账号 token、包含 token 的本地地址、会话导出和私有项目内容。用最小脱敏示例说明受影响的提交、平台、复现步骤与影响。应用各项独立上传开关见[隐私说明](privacy.zh.md)。

## 部署边界

按项目需要授予本地应用权限，并保管好带认证信息的本地地址。公开源码仓库不意味着要将智能体的本地 HTTP 服务暴露到互联网。请先审查自定义 profile、插件、代理或收集器，再决定是否开启。
