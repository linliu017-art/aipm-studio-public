## B · 公司类型套路速查表（调研时按此定位业务）

### B.1 AI + 垂直行业（教育/工业/建筑/核工业 ERP/商业管理/命理玄学）

- **典型岗位画像**：PM 定位偏"行业方案 + AI 能力嫁接"，不是纯 C 端产品经理
- **面试官看重**：你懂不懂对方行业语言
- **已面公司**：四川人瑞（教育/工业/建筑联合共研，7-8 家头部客户 POC 阶段）、郑州引力琥珀（核工业 ERP + AI 工具）、祥瑞福泽（商业管理，郭树准数据不算何锦华）
- **已调研公司**：知否科技（命理玄学垂直）
- **调研必查维度**：
  - 业务阶段（POC / 规模化）
  - 客户联合模式（客户出场景 vs 公司独立立项）
  - 数据壁垒（垂类数据谁提供 / 怎么标注）
  - 行业准入资质（知否「互联网宗教信息服务许可证」就是例子）
- **反问切入点**：
  - "AI 能力是和行业客户联合共研，还是独立立项？"
  - "数据壁垒方面，垂类数据是客户提供还是自建？"
  - "目前 POC 客户和规模化客户比例怎么样？"
- **典型翻车点**：开场不知道公司业务就开答（四川人瑞 Q03 被打断 7 次 / 引力琥珀 Q16 反问才知道核工业 ERP 已经晚了）

### B.2 AI + 内容 / 字节生态（长视频/小游戏/短剧/音视频）

- **典型岗位画像**：工具产品部 PM，管 AI 小工具（生图修图音视频）+ 自然语言 Agent（类 OpenClone）
- **已面公司**：繁华科技（徐文杰一面，团队 2 PM + 2 UI + 产品总监）
- **已调研公司**：芒果TV（长视频头部，山海 AIGC 平台 70+ 场景）、字节抖音生态
- **调研必查维度**：
  - AI 产品规划 vs 已落地比例（繁华真实情况：落地=0，全在规划）
  - 团队结构（PM / UI / 算法 / 业务方）
  - AI 小工具 vs Agent 两大方向的内部优先级
  - 主站 APP 全 AI 化焕新的 AB 测试能力
- **反问切入点**：
  - "AI 产品规划里已经落地的和还在规划的比例怎么样？"
  - "主站全 AI 化焕新的实验机制是什么？"
  - "AI 小工具和 Agent 两条线现在哪条是战略重点？"
- **典型翻车点**：SaaS 商业化 ROI 被面试官"喂结论"只回"差不多"（繁华 Q10.1）；模型比对答偏，漏掉 4×50 证据（繁华 Q09）

### B.3 AI + 工具 / SaaS（已上市营销/销售 SaaS 龙头）

- **典型岗位画像**：企业级 Agent 营销产品 PM，做"通用能力沉淀成 Skill / 业务场景拼接成 Workflow"——是 SaaS 工具的产品化运营，不是纯 C 端创新
- **已调研公司**：迈富时（02556.HK，南京浦口·江浦研发总部，AI 应用 PM 15-30K×15 薪）
- **公司基本面识别信号**（区别于天使轮/初创）：
  - 已上市（港股/A 股）+ 全年盈利（不是烧钱模式）
  - AI+SaaS 收入占总收入 ≥40%（不再是"在规划中"）
  - 模型有自研 + 备案（迈富时 Tforce 国内首个营销垂直网信办备案）
  - 研发总部独立落地（迈富时 2025-12 南京 100 亿 / 5 年 2000 人）
  - 客户留存率（SMB ~90% / KA >100% 是健康水位）
- **调研必查维度**：
  - **L1 招股书 + 年报**（港股上市公司 hkexnews 是金矿，财务/客户数/留存率全披露）
  - 六朵云式产品矩阵（营销云/销售云/商业云/分析云/智能云/组织云）
  - **AI 中台架构**（4 层架构 + N 个核心模块 + 多 Agent 协同）
  - **Tforce 类自研垂类大模型**（参数规模 / 备案 / 多模态能力）
  - 国外对标（HubSpot/Klaviyo/Salesforce）的 AI Agent 落地节奏
  - **Unit Economics 4 档分层**（SMB/中型/KA/超大 KA，每档 ARPU/LTV/CAC/毛利）
  - GEO 赛道（让品牌内容成为 AI 答案的优先引用源 — JD 高频点名）
- **反问切入点**：
  - "AI Agent 当下落地的客户里，POC 阶段 vs 规模化阶段的占比大概是多少？"
  - "营销云和 AI Agent 中台未来 12 个月的战略优先级是什么？"
  - "中小营销场景做 Agent，当下最难做的产品决策是什么？"
- **典型短板（候选人妙甲方法论的迁移缺口）**：
  - **营销行业 know-how 缺**（不懂 CPM/CPS/ROAS/AARRR 营销侧定义）
  - **GEO 零经验**（JD 单独点名，必须 30 天内补 1 篇博客）
  - **Coze/Dify/n8n 简历未写**（JD 加分项，必须 30 天内补 1 个 demo）
  - 企业级 ToB SaaS 客户导向（美团内部 ToB ≠ 企业 SaaS 客户导向）
- **典型亮点（强匹配维度）**：
  - **4 模型 × 50 评测集 = 钻石 case**（直接对应 Skill 体系编排 + 模型能力产品化两个 JD 关键词）
  - **三层接管 + 价格置信度校验**（多 Agent 协同 + 防幻觉，AI-Agentforce 中台同构）
  - **AI Coding（Codex/Cursor）**（JD 加分项 100% 命中）
  - **PRD V4.0 模板（RICE/AARRR/异常处理矩阵齐全）** = 企业级 PRD 能力证据
- **薪资水位**（已上市港股 SaaS 龙头 P5/T5 资深岗）：
  - JD 范围 15-30K × 15 薪 = 22.5-45 万年包
  - 推荐报价 26-28K × 15 薪 = 39-42 万（JD 上限 85-93%）
  - **必问 RSU/期权激励**（已上市公司不问就是白丢）
  - 试用期不接受 80% 打折，要锁转正薪资

### B.5 AI + 知识付费 / IP 矩阵 / 文化传承（国学/出版/教育内容）

- **典型岗位画像**：AI 智能体运营官 / 数字人内容运营 / IP 矩阵号操盘手——**不是纯 PM，是"懂 AI 的内容运营 + Prompt 工程 + 数据驱动 + 矩阵号"四合一**
- **面试官看重**：① 矩阵号实操经验 ② AI 智能体人设搭建能力 ③ 数据驱动运营 ④ 文案功底 + 网感
- **已调研公司**：北京善品堂文化传播（国学出版+AI数字人+知识付费 三件套）
- **薪资水位**：1-3 年「运营官」职级 8-13K 是行业基线（比 PM 低 30-50%），能力优秀线 15-20K
- **调研必查维度**：
  - 集团主体溯源（往往招聘主体是集团旗下子公司，要查工商关系）
  - AI 业务真实进度（已落地 vs 规划中比例，避免入职发现"全在 PPT 里"）
  - 内容资产护城河（已有 IP/学者/版权能否被 AI 二次利用）
  - 抖音/视频号合规（禁完全 AI 无人直播 / 虚拟人需绑实名 / 1/10 画面标"AI生成"）
  - 私域转化漏斗设计（这类公司核心利润来自私域复购）
- **反问切入点**：
  - "AI 智能体业务已落地的和规划中的比例是多少？哪个智能体是 P0？"
  - "更看重 GMV 增长还是私域留存复购？北极星是什么？"
  - "和集团其他主体（出版/教育/线下）是协同关系吗？AI 能复用已有内容资产吗？"
  - "前 3 个月最希望我产出的是什么？数字人矩阵 0-1 还是智能客服 MVP？"
- **典型翻车点**：
  - 简历是产品方向就硬上，不做 PM→运营的迁移叙事（5 大错位风险必须提前打话术）
  - 不懂抖音 AI 政策红线，反问时被面试官当外行
  - 不研究行业 IP（青山老师/罗振宇/樊登）就去面试
  - 数据指标说不清楚（活跃/留存/转化/满意度 JD 第 3 条直接对应）
- **典型亮点（候选人妙甲方法论的迁移钩子）**：
  - 妙甲 AI 客服 4 层架构 = 善品堂智能客服可直接平移
  - Prompt 四件套（角色/约束/样本/格式）= 国学数字人人设搭建底层一致
  - 4 模型×50 评测集 = 国学场景重新跑评测的方法论可直接套用
  - 知识库 RAG + 三层接管 = 国学场景必上 RAG（古文准确性）+ 必上人工兜底（学术可信度）
  - 1 万条评论分析 + 用户分四层 = 国学私域用户调研可直接复用

### B.6 AI + 科研工具 / 学术 Agent（学术 GPT/文献检索/写作辅助）🆕 2026-05-15 新增

- **典型岗位画像**：AI 产品经理面向**科研用户**（硕博/青年教师/PI），核心 = **Agent 工作流产品化 + Skills 评测体系搭建 + 多步骤任务编排**，不是写 PRD 的传统 PM
- **面试官看重**：① 大模型 + RAG + Agent 工程化深度 ② 模型评测体系能力 ③ Tool Calling / 多 Agent 协作经验 ④ 学术领域 domain（加分项，可后补）⑤ 对 AgentSkills / MCP / OpenClaw 等生态的判断力
- **已调研公司**：北京简圣科技（沁言学术 + QinyanClaw 全球首个学术 OpenClaw，CEO 罗实清华 + CSSCI 创始人苏新宁双血缘，20 万 C 端 + 30+ 高校）
- **薪资水位**：3-5 年资深岗 **20-25K × 13 薪** = 26-32.5 万年包（北京水位）；推荐报价 JD 上限 92-100%
- **公司基本面识别信号**：
  - 现金流接近收支平衡（非烧钱模式，BOSS 标"不需要融资"）
  - 学术权威股东 / 顾问（如 CSSCI 创始人苏新宁 → 简圣的学术血缘壁垒）
  - 高校图书馆 B 端渠道（信号：南京财经/大连理工/云南中医/湖北民族等图书馆已开通试用）
  - C 端用户量 ≥10 万（罗实公开 20 万）
  - 创始人 PR 强度高（罗实 3 大媒体专访：K姐独家 / 中华网 / 时代周报）
- **调研必查维度**：
  - 工商档案（成立日期 / 经营资质 / 文化执法检查）→ 简圣 2023 成立 + 广电资质 + 2025-08 检查无问题
  - 创始人背景 + 关键股东（创业经历 / 学术背书 / 上一段创业项目）
  - 产品 5 档定价（Free / Plus / Pro / Max / Ultra）+ B 端高校包年 + Token 沁点付费
  - Agent 框架技术栈（OpenClaw vs Anthropic Codex vs 自研 LangGraph）
  - Skills 生态（GitHub 第三方 Skills 库数量 → 简圣 GitHub LeonChaoX/qinyan-academic-skills 183 个）
  - 学术伦理红线（反代写 / 私有知识库 / 引用溯源 → 简圣"拒绝论文枪手"）
  - 国外对标（Elicit / Consensus Scholar Agent on GPT-5 / SciSpace）
- **反问切入点**（3+3+2 公式简圣版）：
  - 业务："QinyanClaw 在 7×24 后台运行下，Skills 调用成功率和云端任务稳定性指标？"
  - 业务："C 端 20 万和 B 端 30+ 高校的运营策略哪个是未来 12 月战略主线？"
  - 业务："学术浏览器端侧小模型和 QinyanClaw 云端 Agent 的端云协同 roadmap？"
  - 岗位："前 3 个月最希望产出是新 Skill / 新 Agent，还是已有功能转化优化？"
  - 岗位："对接的是算法、工程、还是 CSSCI 学术顾问团？"
  - 个人："产研评测体系（类似 OpenAI Evals）成熟度？官方 Skills 的评测标准？"
- **典型翻车点（必预防）**：
  - **学历字段第 3 连**：DeepWisdom + Weibot + 简圣硕士门槛 = P0 系统性顽疾，必须 24h 内简历补"学校 + 毕业时间 + 专业"
  - **OpenClaw 没碰过**：罗实是技术深究型 BOSS，没有 OpenClaw 生产经验必须坦诚答 + 钩子"和自搭 OpenCode 底层同构"
  - **学术 domain 零积累**：必须 24h 内沁言 / Elicit / Consensus 各跑 1 次任务 + 看 5 篇用户原话
  - **技术名词混淆**：OpenClaw（国产开源框架）≠ Anthropic Codex；AgentSkills（2025-12 开源标准）≠ MCP（Model Context Protocol）≠ Tool Calling（Function Call）≠ A2A
- **典型亮点（候选人方法论 4 钻石迁移钩子）**：
  - **4 模型×50 评测集**（画眉）= Scholar Agent / QinyanClaw Skills 评测体系**完美同构**

## C · 反问 3+3+2 公式（调研时提炼给 Ch11）

公式：**3 个业务问题 + 3 个岗位期待问题 + 2 个个人成长问题 = 8 问**，一面只问前两组，三组合计不超过 8 个。

### 第一组 · 业务类（开场打情报）

1. "贵司目前 AI 产品落地的阶段大概是？是早期 POC 还是已经有规模化客户了？"
   （引力琥珀 Q16 原题验证有效）
2. "AI 能力这块是和行业客户联合共研，还是贵司独立立项？"
   （四川人瑞 R01-R02 拿到 7-8 家客户情报的原问）
3. "产品线上现在最核心要解决的一个用户问题是什么？"
   （引导面试官讲真需求）

### 第二组 · 岗位期待类（收敛到我能做什么）

4. "这个岗位进去后，前 3 个月最希望我产出的是什么？"
   （引力琥珀 Q18）
5. "对接的人主要是谁？是业务方 / 算法 / 设计？"
   （引力琥珀 Q19）
6. "您这边对这个岗位人员的核心能力要求是什么？"
   （引力琥珀 Q2，可诱导面试官说出打分维度）

### 第三组 · 个人成长类（二面或终面才问）

7. "团队内部有没有固定的产品经理成长机制？"
8. "如果顺利入职，半年之后什么样的表现会被认为是优秀？"

### ⚠️ 一面**绝对不问**的反问

- token / AI 工具报销（引力琥珀 Q17、四川人瑞 R03 双双翻车）
- 薪资范围（第 1 场 ToB 公司翻车）
- 加班 / 调休 / 工位 / 5 险 1 金细节

### 🆕 C+ · 反问"打七寸"金钩子追问公式（2026-05-16 升级 · 简圣科技复盘催生）

旧公式（C 节 3+3+2）只解决"问什么"，不解决"接住怎么追"。**简圣一面真实复盘暴露 4 个金钩子从手中滑走**：海外版第一目标市场 / B-C-G 三端营收占比 / SCRM 跑量 CPM 数据 / 这季度 OKR — 全部没追。

**升级公式**：**每个反问 = 1 个开放问 + 1-2 层金钩子追问**

#### C+.1 金钩子追问范式（强制 SOP）

| 第一层反问 | 金钩子追问层（必追）|
|---|---|
| "贵司最大核心痛点是？" | ① 量化口径（"激活到留存时长是几天还是几周？"）② 端别拆分（"B/C/G 哪一端最痛？"）③ 现有手段（"运营现在用什么方法解决？"）|
| "未来产品规划方向是？" | ① 时间窗口（"海外版第一目标市场是北美/欧洲/东南亚？为什么？"）② 资源配置（"研发资源 60%/30%/10% 分到哪三块？"）|
| "客户分层是怎样的？" | ① 营收占比（"B/C/G 三端营收大概几比几比几？"）② 销售模式（"B 端是直销还是渠道？G 端是政府采购还是定制？"）|
| "运营痛点卡在哪？" | ① 投放数据（"现在跑量关键词是哪些 / CPM 大概多少 / ROI 怎么算？"）② 团队规模（"运营、市场、开发各几个人？"）|
| "看重候选人什么能力？" | ① 优先级排序（"如果只能选 3 项，您最看重的 top 3 是？"）② 反例画像（"哪种候选人您一定不要？"）|

#### C+.2 金钩子触发条件

- ✅ 面试官**主动给出量化数据 / 业务现状 / 战略方向**时——必须追细节
- ✅ 面试官**主动暴露痛点 / 失败案例 / 卡点**时——必须追根因
- ✅ 面试官**说出陌生概念**（如 web3 alpha / 算力分账 / 学术超级智能体）时——必须暴露知识缺口反问"能多说两句吗"
- ❌ 不要追：① 已经被否决的话题 ② 显然超出对方信息半径的问题（如初创 5 年后愿景）③ 商业敏感（如具体营收数字、用户数精确口径）

#### C+.3 一句话原则

> **"对方给出高密度信息 = 邀请你追细节"**——不追就是浪费子弹。8 个反问里有 4 个能追到金钩子层 = 这场反问做到位了。

### 🆕 J · 被否决 3 步话术（业务总操盘手类型必备 · 2026-05-16 简圣科技 R03/R03.1 翻车催生）

详见 `archetypes-library.md` Part A.2 业务总操盘手类型。**核心场景**：面试官"喂结论 + 直接否决"——「我们已经实现了」/「热度过去了」/「站不上了」/「不可能成功」。

#### J.1 死刑判决句识别

| 面试官原话 | 真实含义 |
|---|---|
| "我们已经在另一个功能里实现了" | 你的方案过时——换话题 |
| "这个市场窗口已经关了" | 别提"怎么抢心智"——切换到"现状应对" |
| "热度过去了 / 站不上了" | 战略已转向——别活在过去时 |
| "完全没必要做这个事" | 路径错了——回到家底重新摸 |
| "我们底层 [陌生概念] 跟你说的不一样" | 你的对比对象选错——主动暴露知识缺口 |

#### J.2 3 步标准话术

```
Step 1 · 立刻接受（不超过 5 秒）
→ "好的我之前确实没摸过这块" / "啊那我前面的方案是错位的"
（禁止用"是的但是"，禁止用其他维度继续辩护）

Step 2 · 主动暴露知识缺口
→ "您说的那个 [陌生概念 / 已实现功能] 能不能多给我讲两句？
   我特别想知道 ① X ② Y ③ Z"
（把"翻车"转换成"获取家底情报"的二次机会）

Step 3 · 挂可迁移经验（如果有）
→ "这跟我在 [项目 X] 遇到的 [类似问题 Y] 逻辑像，
   我那时是这么解的：[简短一句话]——但我先听听你们怎么做"
（不是要证明自己有方案，是表达"我有迁移基础 + 学习意愿"）
```

#### J.3 反例（简圣 R03.1 翻车原话）

> 候选人原话："是这样子的，你像前两天出的那个 Codex 的手机版，也就是说它可以做到像沁言学术一样..."
> **错误根因**：面试官 R03 否决你的方案核心是"功能我们已经做完了"，**不是**"成本谁高谁低"。候选人跑到一个面试官根本没问的赛道辩论 = 第二次翻车。

#### J.4 一句话原则

> **"被否决后继续辩护 = 第二次翻车，承认 + 反问家底 = 唯一活路"**

### 🆕 D+ · 演示物续场策略（2026-05-16 简圣一面亮点制度化）

简圣科技一面候选人在面试官说"暂时没问题了"时**主动续 15 分钟演示**，把面试从"准备结束"拉回"产品深度讨论" = 本场关键亮点。**应该制度化**到每场面试，不再靠临场发挥。

每个钻石项目（references 评级 ⭐⭐⭐）必须准备：

#### D+.2 续场时机判断

| 时机 | 是否触发续场 |
|---|---|
| 面试官说"你有什么想问我的" | ✅ 反问前/反问后都可以续："反问之前我直接给您看一下我的项目作品会比较快" |

| 时间已过 60 分钟 | ❌ 尊重对方时间 |
| 面试官回应冷淡 / 在打瞌睡 | ❌ 没兴趣 |

#### D+.3 演示物 vs 流水账的区别

⚠️ **简圣 Q07 翻车**：候选人演示妙甲 + 画眉时**报菜名式**罗列功能，没挂故事线。

**正确范式**——每个功能点必须挂 3 件事：

```
① 这个功能解决什么用户痛点（用户场景一句话）
② 用了什么 AI 能力解决（技术亮点一句话）
③ 数据变化（量化指标一句话）
```

> ① 用户咨询"那个款多少钱"时，美甲师不在线 = 漏单高发点

> ③ 价格场景漏单从 18% 降到 3.5%，转化提升 4 倍

#### D+.4 一句话原则

> **"面试官说'没问题了' = 邀请你 show case，不是邀请你结束"**——主动续 15 分钟 demo 是把 50% 翻车场拉回 65% 通过场的关键动作。
