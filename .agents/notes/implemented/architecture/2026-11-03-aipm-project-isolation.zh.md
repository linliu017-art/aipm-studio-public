# Agent Note: AIPM 项目隔离

Status: implemented

[English](2026-11-03-aipm-project-isolation.md) | 中文

## Problem

新对话继承默认工作区，导致无关产品想法收到旧项目名、AGENTS.md 和阶段历史。新想法入口还把方向判断当成了生成完整立项报告的授权。

## Decision

沿用已有工作区身份和不可变的会话 cwd。Host 在可配置的父目录下准备独立想法目录，创建前解析符号链接并拒绝已注册工作区内部的路径，但不将其登记为工作区。Nini Flow 开启 `isolatedIdeas`，其他配置保留原启动策略。全局新建对话打开未分组的独立会话，复用可用空白会话，并在快速点击时共用尚未完成的创建。明确选择工作区则继续该项目。创建失败会显示错误，不回退到旧目录；后续导航取代尚未完成的打开操作。

已有非空对话仍可恢复。没有已保存选择的冷启动打开独立空白会话，不继承最近的项目。选择器和对话页头提供新想法入口，未分组对话的页头显示未归属项目。AIPM 初始化仍由 `aipm_stage` 负责，在请求保存材料时发生，按需登记现有目录、命名工作区并关联当前会话，不改变其身份或路径。已有对话中的跨产品请求不能替换该项目的元数据。

方向判断使用 `idea-refine`，明确要求立项产物才进入立项。技能复用已确认的入口答案和研究选择。跳过竞品不授权研究。普通交流方式要求不写入产品需求。

独立对话在保存项目之前没有工作区。项目目录按产品元数据筛选已登记工作区，不依据标题、文件夹名或对话数量。已有但无效的元数据仍可见，以便修复。旧草稿工作区在明确移除前保留其历史与文件。

新任务导航默认创建全新会话，即使已有尚未发过消息的会话。Host 的空白标记不能证明浏览器草稿为空。文字、引用和附件保留在原会话；启动时恢复选中的草稿，工作区选择器将其携带到全新目标。工坊发送用户任务，流程上下文由 Host 提供。

## Consequences

已有项目文件、工作区身份、会话目录与历史均保留。新想法会增加目录，用户可以重命名工作区或明确选择它继续。该方案不引入会话格式变更或第二套可变项目绑定。Host 需要能访问 Documents 或已配置的想法父目录。除独立导航测试外，还需要真实客户端启动来验证 Cordis Remote 命名空间依赖声明。

## Verification

Host 测试覆盖唯一目录、旧项目文件保留、内部父目录拒绝和创建失败。Client 测试覆盖默认隔离、明确继续、失败显示和导航取代。无需密钥的编排会话通过发布的 headless 配置加载当前 AIPM 提示词和访谈技能。浏览器验证使用正在运行的已认证 Web 应用，私有测评记录保留具体结果及已有无关 GUI 测试失败。构建、文档门禁和静态检查覆盖受影响包与自动生成目录。

## Alternatives considered

仅靠提示词忽略会将旧说明留在当前目录。第二套可变项目绑定可能与文件工具不一致，并要求会话迁移。迁移旧项目目录会给文件和历史带来风险。独立工作区目录保留明确继续的能力，并让任务归属只有一个来源。
