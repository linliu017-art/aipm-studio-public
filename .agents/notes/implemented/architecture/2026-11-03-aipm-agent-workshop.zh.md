# Agent Note: 原生 Agent 工坊适配器

Status: implemented

[English](2026-11-03-aipm-agent-workshop.md) | 中文

## Problem

工作台已有产品技能，但缺少可执行的 Agent 产品组件选型和版本化交付操作。另行运行下载的 Python 应用会增加一套模型配置、工作区目录和交付路径。

## Decision

将 Agent 工坊 MIT 项目的特征目录和确定性选型规则适配到现有 AIPM 包。可发现的技能使用当前会话模型进行推理，aipm_workshop 负责读取、选型、检查和保存。只请求 PRD 时省略工程设计，只保存请求的产物；普通产品 PRD 仍路由到 product-prd。本集成不自动开展外部研究、代码生成或额外模型调用。

使用当前不可变 Session cwd 和已有 aipm_stage 初始化。读取和检查不登记项目。保存时校验原文依据与适用的设计规则，随后使用[统一文档索引](2026-11-03-project-documents.zh.md)，通过一次原子提交关联指定文档版本与内部工坊方案快照。每份文档和工坊流程各自计数版本。旧工坊元数据仍可读取，保留旧文件和人工修改。已有路径祖先和版本元数据必须位于所选项目内部。

独立的工坊导航打开只读入口页，开始任务时只发送一次用户内容和结构化流程选项，Host 加载当前作用域的技能，将正文与所选流程作为 skill-invocation 上下文记录，不把后台说明放进用户消息；接受后才进入会话，失败时保留表单供重试。各模式不继承项目上下文，只有明确选择项目才把本次会话关联到该项目。原有未发送草稿保持不变，页面导航不登记工作区。

项目详情允许用户修改自动生成的项目名称。Host 同步提交项目元数据和工作区标题，标题持久化失败时恢复元数据。阶段更新共用文件锁，保留用户名称和阶段进度；项目目录及已导出文档的路径和内容保持不变。

## Consequences

无需 Python 运行时或额外凭据。提案和保存请求保留在普通工具历史中。组件判断和原始材料仍是模型输入，引用匹配不能证明事实真实或用户已批准。机械检查不提供独立审稿、实现或验收证据。版本目录是不可变导出物，不是可变的当前文档镜像。最新版本损坏时阻止继续保存，不静默回退。

## Verification

真实 Loader 测试覆盖工具操作与释放。文件系统测试覆盖请求产物、人工修改保留、无依据引用拒绝、畸形版本、并发过期写入和路径重定向。无密钥的人工编写会话通过已发布 headless 配置覆盖模型可见调用。浏览器检查覆盖技能发现、实际模型起草、项目产物与版本化迭代。来源授权记录及打包资源校验覆盖导入方法。

## Alternatives considered

仅添加链接或复制技能不能执行规则或保护版本。启动上游应用会重复模型配置与项目存储。隐式额外模型调用需要额外的日志编排，并会误导当前审稿证据，因此适配器明确报告机械检查。
